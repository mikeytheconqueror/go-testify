# go-testify (first-iteration)

Проект, демонстрирующий модульное и интеграционное тестирование в Go с использованием стандартных инструментов **testify** и Go.

Этот репозиторий содержит примеры того, как структурировать и писать тесты для серверного кода в Go, используя:
- `github.com/stretchr/testify/assert`
- `github.com/stretchr/testify/require`
- `net/http/httptest`

## Цель проекта

Цель этого проекта - показать, как писать:
- Понятные и поддерживаемые модульные тесты
- Надежные интеграционные тесты для обработчиков HTTP и логики базы данных
- Тесты с помощниками по утверждению от Testify
